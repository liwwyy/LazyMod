# Changelog

## [1.0.0] — 2026-10-28

- Initial Fabric client mod for Minecraft 26.2, Java 25.
- AutoClicker with immutable Raidfarm/Spawner presets and editable local profiles.
- Independent left/right conditions, exact intervals, real attack cooldown and right hold.
- Standalone and profile-integrated AutoEat with shared input ownership.
- YACL configuration, unbound configurable activation keys and client-only `/lazy` commands.
- Validated local installation, JUnit/installer tests and GitHub CI/tagged releases.

Runtime verification is pending; see README for the focused manual checklist.
